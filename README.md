# 🍽️ DineSpot – Where Table Awaits

DineSpot is a full-featured Android restaurant booking application that allows users to reserve tables, order food, and make secure online payments.  
The application includes both **User** and **Admin** modules with Firebase integration and Razorpay payment gateway.

---

## 📌 Project Overview

DineSpot simplifies restaurant reservations by providing a complete digital booking system.  
Users can book tables, order food, manage their cart, and make secure payments online.  
Admins can monitor all booking activities through a dedicated dashboard.

---

## 👥 User Roles

### 👤 User
- Register & Login (Firebase Authentication)
- Browse Restaurants
- Book Tables
- Order Food
- Add items to Cart
- Edit/Delete Cart Items
- View Order Summary
- Make Payment via Razorpay
- View Order History in Profile
- Submit Feedback & Contact Support

### 👨‍💼 Admin
- Register & Login
- View Complete Booking History
- Monitor User Orders

## 🧭 App Flow

---

## 🍽️ Booking & Ordering Process

1. Select Restaurant
2. Book Table
3. Select Food Items
4. Add to Cart
5. Proceed to Order Summary
6. View All Selected Items
7. Payment via Razorpay
8. Payment Status:
   - ✅ Success → Order Stored in Firebase → Visible in Profile
   - ❌ Failure → Transaction Cancelled
